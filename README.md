# LLM Evaluation Framework (Python)

This repository contains a simple and practical framework to evaluate Large Language Model (LLM) responses using Python, prompts, and labeled datasets.

The goal of this project is to demonstrate how AI outputs can be evaluated in a structured and repeatable way, focusing on reliability, consistency, and hallucination reduction rather than raw model performance.

LLM systems often fail not because of the model itself, but due to missing evaluation logic. This project shows how to define expectations, validate responses against clear rules, and generate human-readable evaluation results.

## Project Overview

The evaluation process follows these steps:

1. Load a labeled evaluation dataset containing questions, expected answers, and validation rules.
2. Apply a controlled system prompt to guide the assistant’s behavior.
3. Generate responses (using mock outputs by default).
4. Evaluate responses using simple rule-based metrics such as required keywords, forbidden terms, and response length.
5. Produce a summary report highlighting pass/fail results and common failure patterns.

The framework is intentionally lightweight and easy to understand, focusing on clarity and correctness rather than complex machine learning pipelines.

## Repository Structure

- `data/` contains the evaluation dataset used for testing LLM responses.
- `prompts/` contains the system prompt that defines assistant behavior.
- `src/` contains the Python scripts responsible for running the evaluation and computing metrics.
- `results/` contains a sample evaluation report generated by the framework.

## Evaluation Criteria

Each response is evaluated based on:
- Presence of required keywords.
- Absence of forbidden or hallucinated terms.
- Maximum allowed number of sentences.
- Correct handling of unknown or unsupported questions.

These checks simulate real-world constraints commonly required in production AI systems.
